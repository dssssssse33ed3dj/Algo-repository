# Домашнее задание № 2 · Сложность и O-нотация

Эта работа проверяет не запоминание названий классов сложности, а умение читать
код и соотносить его с ограничением задачи. Сначала оцените двенадцать фрагментов,
затем выберите подход для шести ограничений и разберите готовую функцию, где
стоимость одной строки легко недооценить.

## Три части работы

В `fragments.py` для каждой функции укажите время (`TIME`) и память (`SPACE`) в
`answers.py`; для двух функций добавьте худший случай (`WORST_CASE`). Проверка:

```text
pytest homework/02-complexity/test_lesson_03.py -q
```

В `limits.md` выберите решение для шести задач. Обоснуйте выбор расчётом числа
операций; ориентир — около 10⁷ простых операций в секунду. Здесь можно спросить
ИИ о варианте решения, но расчёт и вывод проверяете сами.

В `acceptance.md` разберите функцию из `acceptance_vetclinic.py`: время, память,
худший случай и скрытую стоимость операции. Эту часть выполняйте без ИИ.
