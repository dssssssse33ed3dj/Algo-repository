# 07. Максимальная серия

## Задача

Напишите `longest_run(numbers)`. Верните длину самой длинной подряд идущей серии одинаковых чисел. Для пустого списка верните 0.

## Входные данные

Список `numbers` из `n` целых чисел.

## Выходные данные

Одно целое число.

## Пример

```text
[1, 1, 2, 2, 2, 3] → 3
```

## Данные для замеров

Первые два набора показывают рост времени. Третий проверяет особый случай. Его время запишите в отдельный столбец.

1. 1 000 случайных чисел.
2. 100 000 случайных чисел.
3. 100 000 чисел, длинная серия в конце.

## Сценарии

1. `n = 10 000 000`, дополнительная память не более 8 МБ.
2. `n = 100`, нужен быстрый ответ для одного списка.
