# Задание 7 · Алгоритмы курса в программных системах

Алгоритмы из курса работают внутри привычных инструментов. В Redis политика
вытеснения выбирает ключ для удаления, словарь Python ищет значение по ключу,
а Git вычисляет имя объекта из его содержимого. По документации разберите эти
три случая и напишите короткую функцию для формата Git.

**Изучили раньше:** хеш-таблица изнутри (модуль 0 книги «Хеш-структуры»),
словарь и множество (модули 17 и 19), кэш и LRU (модуль 20).

**Материалы:** https://algorthimization-course-vvodnoe.vercel.app/op04-algoritmizaciya/hesh/
