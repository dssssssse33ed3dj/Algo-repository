# 01. Минимальное число

## Задача

Напишите `find_min(numbers)`. Верните минимальное число из непустого списка целых чисел.

## Входные данные

Список `numbers` из `n` целых чисел.

## Выходные данные

Одно целое число — минимум.

## Пример

```text
[8, 3, 11, -2, 5] → -2
```

## Данные для замеров

Первые два набора показывают рост времени. Третий проверяет особый случай. Его время запишите в отдельный столбец.

1. 1 000 случайных чисел.
2. 100 000 случайных чисел.
3. 100 000 чисел, минимум в конце.

## Сценарии

1. `n = 10 000 000`, дополнительная память не более 8 МБ.
2. `n = 100`, исходные данные менять нельзя; ответ нужен без подготовки отдельной структуры.
