## Работа с репозиторием

Создайте репозиторий кнопкой **Use this template** и склонируйте его в VS Code.
Для запуска программ нужен Python 3.12 и окружение с зависимостями:

```text
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

В Windows создайте окружение командой `py -m venv .venv`, затем выполните
`.venv\Scripts\Activate.ps1`.
