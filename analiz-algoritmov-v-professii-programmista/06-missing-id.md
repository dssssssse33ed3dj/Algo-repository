# 06. Пропущенный номер

## Задача

Напишите `missing_id(ids, n)`. В `ids` лежат все числа от 0 до `n`, кроме одного. Верните пропущенное число.

## Входные данные

Список `ids` и число `n`.

## Выходные данные

Одно целое число.

## Пример

```text
ids = [3, 0, 1], n = 3 → 2
```

## Данные для замеров

Первые два набора показывают рост времени. Третий проверяет особый случай. Его время запишите в отдельный столбец.

1. `n = 1 000`, список перемешан.
2. `n = 100 000`, список перемешан.
3. `n = 100 000`, пропуск в начале.

## Сценарии

1. `n = 10 000 000`, дополнительная память не более 8 МБ.
2. `n = 100`, нужен быстрый ответ, исходный список сохраняется.

Вывод
Для сценария 1 выбираю формулу суммы, потому что она позволяет найти пропущенное число за один проход по списку, используя O(1) дополнительной памяти. Также этот вариант показал лучшее время на больших наборах - 1.103 мс.

Для сценария 2 выбираю формулу суммы, потому что она показала хорошее время даже на небольших наборах, не требует дополнительной структуры и не изменяет исходный список.
