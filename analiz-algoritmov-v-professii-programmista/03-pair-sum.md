# 03. Пара с заданной суммой

## Задача

Напишите `has_pair_sum(numbers, target)`. Верните `True`, если два элемента с разными индексами дают сумму `target`.

## Входные данные

Список `numbers` и целое `target`.

## Выходные данные

`True` или `False`.

## Пример

```text
numbers = [2, 7, 11, 15], target = 9 → True
```

## Данные для замеров

Первые два набора показывают рост времени. Третий проверяет особый случай. Его время запишите в отдельный столбец.

1. 1 000 случайных чисел.
2. 100 000 случайных чисел.
3. 100 000 чисел, подходящая пара в конце.

## Сценарии

1. `n = 2 000 000`, дополнительная память не более 16 МБ.
2. `n = 100`, список отсортирован, нужен быстрый ответ.

Вывод
Для сценария 1 выбираю перебор с использованием множества дополнений только при условии, что память позволяет хранить необходимые значения - имеет сложность O(n) и быстрее остальных вариантов, но при ограничении в 16 МБ этот вариант нельзя считать подходящим без дополнительной проверки фактического объёма памяти.

Для сценария 2 выбираю два указателя, потому что список уже отсортирован. 1 указатель начинает движение с начала списка, второй - с конца. В зависимости от полученной суммы указатели перемещаются навстречу друг другу. Это позволяет решить задачу за O(n) без необходимости создавать дополнительную структуру.
