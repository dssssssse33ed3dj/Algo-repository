# 05. Общие числа двух списков

## Задача

Напишите `common_unique(left, right)`. Верните общие числа без повторов в возрастающем порядке.

## Входные данные

Два списка целых чисел `left` и `right`.

## Выходные данные

Список общих чисел.

## Пример

```text
[1, 2, 2, 4], [2, 2, 3] → [2]
```

## Данные для замеров

Первые два набора показывают рост времени. Третий проверяет особый случай. Его время запишите в отдельный столбец.

1. Два списка по 1 000 чисел.
2. Два списка по 100 000 чисел.
3. Два отсортированных списка по 100 000 чисел.

## Сценарии

1. В каждом списке 1 000 000 чисел, свободной памяти мало.
2. В каждом списке 100 чисел; входные списки изменять нельзя.
