# 05. Общие числа двух списков

## Задача

Напишите `common_unique(left, right)`. Верните общие числа без повторов в возрастающем порядке.

## Входные данные

Два списка целых чисел `left` и `right`.

## Выходные данные

Список общих чисел.

## Пример

```text
[1, 2, 2, 4], [2, 2, 3] → [2]
```

## Данные для замеров

Первые два набора показывают рост времени. Третий проверяет особый случай. Его время запишите в отдельный столбец.

1. Два списка по 1 000 чисел.
2. Два списка по 100 000 чисел.
3. Два отсортированных списка по 100 000 чисел.

## Сценарии

1. В каждом списке 1 000 000 чисел, свободной памяти мало.
2. В каждом списке 100 чисел; входные списки изменять нельзя.

Вывод
Для сценария 1 выбираю два указателя, потому что они позволяют сравнивать элементы за O(n + m), используя O(1) дополнительной памяти - это полезно при ограниченном объёме свободной памяти, но входные списки должны быть отсортированы заранее.

Для сценария 2 выбираю пересечение множеств, потому что оно показало хорошую скорость на небольших наборах и не изменяет исходные списки. При размере всего 100 элементов дополнительная память не является серьёзной проблемой.
